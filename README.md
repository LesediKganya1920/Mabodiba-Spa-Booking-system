# Mabodiba Spa Booking System 🌿

## Problem

Mabodiba Spa clients were experiencing issues with bookings, including submitting requests without knowing whether they had been approved or confirmed.

## Solution

I built a web-based booking system to simplify the spa booking process and help manage customer appointments more efficiently.

### Features

* Online spa bookings
* Service and date selection
* Customer booking details
* Booking approval/status
* Improved appointment management

### Technologies

HTML • CSS • JavaScript • Git/GitHub

**Goal:** Improve the customer booking experience while helping the spa manage appointments in a more organised way.
